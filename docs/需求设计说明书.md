# bit_pouch 需求设计说明书

> 功能唯一活文档。按功能组织，描述**当前应具备的能力**与验收口径；实现历史见 `docs/变更归档.md`。

## 1. 产品定位

面向开发者、运维、测试与学生的**本地优先工程工具集合**。核心价值不是“工具最多”，而是：

- 常用工具**打开快、算得快、不打断思路**。
- 数据**不离开设备**，适合处理配置、报文、密钥片段等敏感输入。
- 桌面与手机**同一套体验**，随时可用。
- 工具可以**低成本增加**，不被主站业务绑架。

## 2. 目标用户与场景

| 用户 | 典型场景 | 关键诉求 |
|------|---------|---------|
| 后端/前端工程师 | 格式化接口响应、核对长 id、编码转换 | 快、保留精度、可复制 |
| 嵌入式/协议工程师 | 拆帧、看字节、算 CRC | 字段模板、校验值、逐字节视图 |
| 运维/网络工程师 | 算子网、核对 IP 类型 | 结果准确、范围清晰 |
| 学生/学习者 | 进制与编码练习 | 逐字码位、可解释结果 |
| 普通用户 | 临时粘贴 JSON/Base64 | 不安装也能用（PWA）、无广告 |

## 3. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 首页可交互 < 1s（桌面本地构建）；工具切换 < 50ms；1MB JSON < 300ms；按键不阻塞 > 16ms |
| 离线 | 首次加载后核心工具完全离线；不依赖 CDN/远程字体 |
| 隐私 | 输入不写存储、不联网；只有选项/收藏/最近/主题/语言持久化 |
| 跨端 | Web/PWA、Windows/macOS/Linux、Android/iOS 同源；≥900px 桌面布局，<900px 移动布局 |
| 可访问性 | 键盘可达；焦点可见；图标按钮有 aria-label；对比度满足 WCAG AA（正文） |
| 可靠性 | 所有错误有可读文案；Worker 超时/不可用有回退；旧请求不覆盖新结果 |
| 可维护性 | 新增工具只加目录；清单错误在构建期失败；逻辑有单测 |
| 国际化 | 中文/英文完整；工具清单与错误文案都双语 |

## 4. 功能需求

### 4.1 工具箱首页

- 展示全部工具卡片：图标、名称、描述、分类、运行时标记。
- 搜索：匹配中英文名称、描述、id、关键词；大小写不敏感。
- 分类筛选：全部 / 编码 / 转换 / 解析 / 网络 / 文本；分类数量实时统计。
- 收藏：卡片星标切换；收藏区置顶；收藏持久化。
- 最近使用：打开工具即记录，最多 8 个，首页展示前 4 个。
- 命令面板：`Ctrl/Cmd+K` 打开；输入即搜；↑↓ 选择、Enter 打开、Esc 关闭。
- 排序：按 manifest `order`，再按中文名排序；新增工具缺省排后。
- 空态：无匹配时给出明确提示。

**验收**：新增一个插件目录后，重启 dev server 即出现在首页，无需修改任何全局文件。

### 4.2 JSON 格式化

**能力**

- 格式化：2 空格 / 4 空格 / Tab 缩进。
- 压缩：单行输出。
- 键名排序：递归、按码位比较、稳定排序、重复键保持相对顺序。
- 语法高亮：键名、字符串、数字、布尔、null、标点分色。
- 错误定位：错误码、行、列、字符、所在行文本。
- 统计：行数、字符数、UTF-8 字节数。
- 操作：示例、清空、复制输出、`Ctrl+Enter` 运行。
- 输入 Tab 插入当前缩进。

**正确性边界（必须保持）**

- 保留数字原始字面量：`12345678901234567890`、`1.0`、`1E+3`、`-0.5` 原样输出，不经过 `JSON.parse` 的双精度。
- 保留字符串原始转义：`\u00e9`、`\n`、`\"` 不改写。
- 保留重复键。
- 拒绝：空内容、非法字符、未闭合字符串、非法转义、非法数字、缺冒号/逗号、尾逗号、结束后多余内容。
- 嵌套上限 200 层；超过返回 `tooDeep`。
- 空对象/空数组保持 `{}` / `[]` 单行。
- 输出超过 200,000 字符时关闭语法高亮，直接显示纯文本。

**运行时**：Worker。

### 4.3 字符编码转换

**格式**

Unicode 转义、HTML 实体、URL、Base64、UTF-8 字节（HEX）。

**能力**

- 编码 / 解码双向切换；一键交换输入输出并反转方向。
- 输入防抖 120ms 实时转换。
- 逐字码位表：字符、码位（U+XXXX）、十进制、UTF-8 字节、HTML 实体；最多 500 字，超出提示。
- 统计：字符数、UTF-8 字节数。
- 复制结果。

**正确性边界**

- Unicode 编码只转非 ASCII；非 BMP 字符输出 UTF-16 代理对（如 `😀` → `\uD83D\uDE00`）。
- Unicode 解码接受 `\uXXXX`、`\u{XXXXX}`、`U+XXXX`（含多个 `U+` 连写）；不符合模式的原样保留。
- HTML 实体：`& < > " '` 用命名实体，其余非 ASCII 用十进制数字实体；解码支持 `&#123;`、`&#x7B;`、常见命名实体与 `&nbsp;`；未知实体原样保留。
- URL：`encodeURIComponent` / `decodeURIComponent`；非法编码返回 `invalidUrl`。
- Base64：按 UTF-8 字节编码；分块避免大文本参数上限；解码忽略空白、允许省略末尾 `=`；非法返回 `invalidBase64`。
- HEX：编码输出空格分隔大写；解码接受空格/逗号/换行、`0x`、`\x`、连续写法；奇数位或非法字符返回 `invalidHex`。
- 逐字表始终描述“语义文本”：编码时看原输入，解码时看还原结果。

**运行时**：主线程。

### 4.4 进制转换

**能力**

- 源进制 / 目标进制：2–36。
- 常用进制快捷：2、8、10、16、36 一次展示。
- 输入实时转换（60ms 防抖）。
- 结果表：每个目标进制的值、是否精确；近似值标记 `≈`。
- 位宽统计；目标进制结果高亮。
- 每个结果可复制。
- 支持小数、正负号、空格/下划线、`0x`/`0b`/`0o` 前缀（仅进制匹配时剥离）。

**正确性边界**

- 整数用 BigInt 精确计算，超过 2^53 不丢精度。
- 小数按目标进制逐位乘取整，最多 16 位；除不尽标记近似并去掉末尾 0。
- `0.1₁₀ → 二进制` 必须标记近似；`10.5₁₀ → 1010.1₂` 精确。
- 错误：空输入、超长（2000 字符）、多个小数点、数字超出进制范围（指出具体字符与进制）、进制越界。
- 负零输出 `0`，不带负号。

**运行时**：主线程。

### 4.5 报文解析

**能力**

- 输入模式：十六进制 / 文本（UTF-8）。
- HEX 接受空格、逗号、分号、冒号、中文标点、换行、连续写法、`0x`/`\x` 前缀。
- 字段模板：每行“字段名 + 分隔符 + 字节数”，支持 `:`、`：`、`,`、`，`、空白；支持 `#` 注释、行尾注释、单位“字节/B/bytes”。
- 字段切分：名称、偏移、声明长度、实际长度、HEX、ASCII、大端十进制整数（字段 ≤ 8 字节）。
- 报文不足时字段标记 `truncated`，不越界。
- 模板未覆盖的尾部显示为“其余”。
- 无效模板行按行号提示，其余行继续解析。
- 逐字节视图：偏移、HEX、十进制、二进制、可见 ASCII；最多 512 行。
- 校验值：整包与“除末尾 2 字节”两种口径的 SUM8、XOR8、SUM16、CRC16/MODBUS。
- 上限 65,536 字节；超出返回 `tooLong`。
- ASCII 视图：空格显示 `␠`，不可见字符显示 `·`。

**验收**：Modbus 帧 `01 03 00 00 00 0A C5 CD` 的整包 CRC16 为 `0000`，除末尾 2 字节口径为 `CDC5`。

**运行时**：主线程。

### 4.6 子网计算

**能力**

- 输入 IPv4 与掩码/前缀；支持 `192.168.1.10/24` 内联前缀。
- 掩码接受 `24`、`/24`、`255.255.255.0` 三种写法。
- 滑块选择前缀 0–32，与掩码输入双向同步。
- 结果卡片：网络地址/CIDR、广播地址、首个可用、最后可用、掩码、通配符、可用主机数、地址总数、地址类型。
- 二进制对照：地址（网络位与主机位用竖线分隔）、网络地址、广播地址。
- 地址类型：PRIVATE / SHARED(CGNAT) / LOOPBACK / LINK_LOCAL / MULTICAST / RESERVED / PUBLIC。
- 每项可复制。
- 输入实时计算（90ms 防抖）。

**正确性边界**

- `/0`、`/16`、`/24`、`/30`、`/31`、`/32` 的主机数口径：`/0–/30` 扣网络与广播；`/31` 两点都可用；`/32` 单机可用。
- 非连续掩码（如 `255.0.255.0`）返回 `maskNonContiguous`。
- 每段必须是 0–255 的十进制；段数不足、越界、非数字返回 `ipInvalid`。
- 位运算必须用 `>>> 0` 保持 32 位无符号。

**运行时**：主线程。

### 4.7 JWT 解析

- 输入 JWT 或 `Bearer <token>`；支持两段（无签名）与三段令牌。
- 输出 header、payload 格式化 JSON，算法、签名段长度、iat/nbf/exp 与剩余时间。
- 过期判断基于当前时间；无 exp 显示“无 exp”。
- 明确提示“只读、不验签”，不调用任何加密库。
- 错误码：`empty`、`tooLong`、`invalidJwt`、`invalidHeader`、`invalidPayload`。
- 运行时：主线程。

### 4.8 哈希与校验

- 算法：MD5、SHA-1、SHA-256、SHA-384、SHA-512、CRC32；可多选，默认 MD5 + SHA-256。
- 文本按 UTF-8 编码，上限 1,000,000 字符；空串也是合法输入。
- 输出 HEX 或 Base64；每个算法单独展示并逐条复制。
- 文件模式：选择文件后对同一组算法计算摘要，上限 64 MB；文件不离开设备。
- HMAC：填写密钥后只保留 SHA 系列，MD5/CRC32 自动跳过；密钥不落盘、不回显。
- 期望值：粘贴摘要后忽略大小写比对，命中/不命中明确标识。
- MD5/SHA-1 显示“不适合安全用途”提示。
- 错误码：`invalidAlgorithm`、`noAlgorithm`、`tooLong`、`cryptoUnavailable`、`fileTooLarge`。
- 运行时：Worker（文本）；文件模式在主线程读取后调用同一核心。

### 4.9 时间工具箱

- 四种模式：时间戳、日期差、日期加减、Cron。
- 时间戳：输入 Unix 秒/毫秒或 ISO 8601 日期；自动模式按 10/13 位区分秒与毫秒，也可强制单位。
- 输出 Unix 秒、毫秒、ISO 8601、UTC、所选时区与本机时间。
- 时区：IANA 列表，默认本机；夏令时交给 `Intl`；非法时区返回 `invalidTimeZone`。
- 日期差：两行输入，拆分天/时/分/秒并给出总时长；两行都支持时间戳或日期字符串。
- 日期加减：分钟/小时/天/周/月/年；月份按日历语义并夹到目标月末。
- Cron：5 段或 6 段（秒），支持 `*`、`*/n`、`a-b`、列表与月份/星期缩写；显示未来 1–20 次执行；按浏览器本地时区求值，时区选择只影响展示。
- 兼容旧行为：默认模式为时间戳转换，结果保留 `milliseconds` 字段。
- 错误码：`empty`、`tooLong`、`invalidInput`、`outOfRange`、`invalidTimeZone`、`invalidAmount`、`invalidUnit`、`invalidCron`、`cronNoMatch`、`diffEmpty`。
- 运行时：主线程。

### 4.10 随机生成器

- 类型：密码、PIN、UUID v4/v7、ULID、NanoID、随机字节、随机整数、抽取、洗牌、分组。
- 密码：长度 4–128，可选大小写/数字/符号，可排除易混淆字符并保证每类至少一个；显示熵（bits）与强度档位。
- 批量上限 200；随机字节单条 1–1024 B，支持 HEX / Base64。
- 随机整数：最小/最大值，可选不重复；区间不足时返回可读错误。
- 抽取/洗牌/分组：每行一个条目；抽取数量不超过条目数，分组数介于 2 与条目数之间。
- 全部随机数来自 Web Crypto，缺失时报错，不退回 `Math.random`。
- 错误码：`invalidMode`、`invalidCount`、`invalidLength`、`noCharset`、`lengthTooShort`、`cryptoUnavailable`、`invalidRange`、`rangeTooSmall`、`notEnoughItems`、`invalidAlphabet`、`invalidGroupCount`。
- 运行时：主线程。

### 4.11 UUID 生成

- 输入为空时批量生成 UUID v4（1–100 个）；输入非空时解析版本与变体。
- 选项：数量、大写、是否保留连字符。
- 随机源优先 `crypto.getRandomValues`，缺失时回退 `Math.random`。
- 错误码：`invalidCount`、`invalidUuid`。
- 运行时：主线程。

### 4.12 URL 解析

- 拆解 protocol、username、password、host、hostname、port、pathname、search、hash、origin。
- 查询参数保留顺序与重复键，同时给出解码值与原始值；`+` 按空格解码。
- 需要完整协议；相对 URL 返回 `invalidUrl`。
- 错误码：`empty`、`tooLong`、`invalidUrl`。
- 运行时：主线程。

### 4.13 正则测试

- 正则与 flags 独立输入；flags 允许 `dgimsuy`，未写 `g` 时内部补全以展示全部匹配。
- 输出匹配索引、匹配值、普通捕获组与命名组；最多 500 条并标记截断。
- 支持替换预览（`$1`、命名引用等）。
- 测试文本上限 20,000 字符，降低灾难性回溯影响。
- 错误码：`emptyPattern`、`invalidPattern`、`invalidFlags`、`tooLong`、`invalidReplacement`。
- 运行时：主线程。

### 4.14 设置

- 主题：深色 / 浅色，持久化，跟随首次系统偏好。
- 语言：中文 / English，持久化；切换后清单与 UI 立即更新。
- 隐私说明：明确“输入不上传、不落盘”。
- 数据：清除最近使用；清除全部本地数据（含主题/语言/收藏/选项，刷新生效）。
- 关于：版本号（`VERSION` 注入）、运行形态（Web/PWA、桌面、移动）、插件机制。
- 快捷键说明。

### 4.15 插件平台

- 目录约定自动注册；清单校验；构建期 `npm run check:plugins` 闸门。
- 脚手架 `npm run plugin:new` 生成五件套。
- 统一 `run` 契约与 `ToolResult` 错误格式。
- main/worker 运行时选择；Worker 超时、回退、序号守卫。
- 共享 UI 组件与 core API。
- 插件开发指南与评审清单。

## 5. 平台要求

### 5.1 Web / PWA

- 静态托管即可运行；hash 路由。
- 可安装到桌面/主屏；离线打开核心工具。
- 非安全上下文剪贴板回退。

### 5.2 Desktop

- Tauri 2；Windows/macOS/Linux。
- 全局快捷键 `Ctrl+Shift+B` 显示/隐藏窗口。
- 单实例；重复启动聚焦已有窗口。
- 图标、窗口尺寸、最小尺寸按 `tauri.conf.json`。

### 5.3 Mobile

- Tauri 2 Android/iOS；响应式布局、底部导航、安全区。
- 触控目标 ≥ 34px；输入法弹出时工具区可滚动。
- 不编译桌面专属插件（`#[cfg(desktop)]`）。

### 5.4 发布与分发

- **出包**：`.github/workflows/release.yml` 以 `v*` tag 触发，三平台矩阵构建：
  - Windows：NSIS 安装版 + 免安装 zip（矩阵带 `--target x86_64-pc-windows-msvc`，产物在 `target/<triple>/release`）。
  - Linux：deb + AppImage。
  - macOS：universal dmg（arm64 + x86_64，未签名 / 未公证）。
  - Web/PWA：`npm run build` 的 `dist/` 打成 `_web.zip`。
- **发布形态**：所有产物进同一个 GitHub **draft** Release，人工确认后 Publish；不自动发布。
- **产物命名**：`bit_pouch_<版本>_x64-setup.exe` / `_x64-portable.zip` / `_amd64.deb` / `_amd64.AppImage` / `_universal.dmg` / `_web.zip`。
- **校验**：`npm run verify:release` 校验 `VERSION`（`V<主>.<次>`）、`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 的版本一致；CI 的 `verify` job 再拉取 Release 资产，确认六类文件齐全。
- **分发**：ihomy 发布页 `https://ihomy.top/bit-pouch`（`/bit-pouch`，alias `/bit_pouch`）统一指向 `https://ihomy.top/files/bit_pouch/<文件名>`；服务器由 `scripts/ihomy-mirror/` 的 systemd 定时器每日从 GitHub `/releases/latest` 同步（天然排除 draft / prerelease），先落安装包、最后原子替换 `release.json`，旧版本只增不删。GitHub Releases 作为备用入口。每个资产按 GitHub API 的 sha256 digest 校验；直连被限速/中断时经可配置加速前缀下载（失败或校验不过自动回退直连），代理只搬字节、不参与信任链。
- **更新**：当前不接 `tauri-plugin-updater`，无签名校验、无 `latest.json`、无应用内自动更新；覆盖安装保留本地偏好。
- **安全边界**：镜像只搬文件、不改写；nginx 对 `/files/` 静态直出补 `X-Content-Type-Options: nosniff` 与 HSTS；当前无代码签名，发布页明确提示 Windows SmartScreen / macOS 首次打开方式。

## 8. 验收标准

## 9. 路线图

| 版本 | 主题 | 候选工具/能力 |
|------|------|--------------|
| V0.2 | 工程常用 | JWT 解析、Hash（MD5/SHA）、时间戳、UUID、URL 解析、正则测试 |

## 10. 风险与待决

- Tauri 移动端真机未验证；剪贴板/输入法/滚动需回归。
- 全局快捷键可能与系统或其他应用冲突，后续提供自定义。
- 运行时插件涉及安全模型，V0.1 不做；若做必须先定义签名、权限、沙箱与版本兼容。
- 许可证未定；对外分发前需明确。
