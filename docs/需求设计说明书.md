# bit_pouch 需求设计说明书

> 功能唯一活文档。按功能组织，描述**当前应具备的能力**与验收口径；实现历史见 `docs/变更归档.md`。

## 1. 产品定位

面向开发者、运维、测试与学生的**本地优先工程工具集合**。核心价值不是“工具最多”，而是：

- 常用工具**打开快、算得快、不打断思路**。
- 数据**不离开设备**，适合处理配置、报文、密钥片段等敏感输入。
- 桌面与手机**同一套体验**，随时可用。
- 工具可以**低成本增加**，不被主站业务绑架。

## 2. 目标用户与场景

| 用户 | 典型场景 | 关键诉求 |
|------|---------|---------|
| 后端/前端工程师 | 格式化接口响应、核对长 id、编码转换 | 快、保留精度、可复制 |
| 嵌入式/协议工程师 | 拆帧、看字节、算 CRC | 字段模板、校验值、逐字节视图 |
| 运维/网络工程师 | 算子网、核对 IP 类型 | 结果准确、范围清晰 |
| 学生/学习者 | 进制与编码练习 | 逐字码位、可解释结果 |
| 普通用户 | 临时粘贴 JSON/Base64 | 不安装也能用（PWA）、无广告 |

## 3. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 首页可交互 < 1s（桌面本地构建）；工具切换 < 50ms；1MB JSON < 300ms；按键不阻塞 > 16ms |
| 离线 | 首次加载后核心工具完全离线；不依赖 CDN/远程字体 |
| 隐私 | 输入不写存储、不联网；只有选项/收藏/最近/主题/语言持久化 |
| 跨端 | Web/PWA、Windows/macOS/Linux、Android/iOS 同源；≥900px 桌面布局，<900px 移动布局 |
| 可访问性 | 键盘可达；焦点可见；图标按钮有 aria-label；对比度满足 WCAG AA（正文） |
| 可靠性 | 所有错误有可读文案；Worker 超时/不可用有回退；旧请求不覆盖新结果 |
| 可维护性 | 新增工具只加目录；清单错误在构建期失败；逻辑有单测 |
| 国际化 | 中文/英文完整；工具清单与错误文案都双语 |

## 4. 功能需求

### 4.1 工具箱首页

- 展示全部工具卡片：图标、名称、两行描述；分类由筛选条表达，运行时标记不上卡片。
- 搜索：匹配中英文名称、描述、id、关键词；大小写不敏感。
- 分类筛选：全部 / 编码 / 转换 / 解析 / 网络 / 文本；筛选项不显示计数，当前结果数见区块标题。
- 收藏：卡片星标切换；收藏区置顶；收藏持久化。
- 最近使用：打开工具即记录，最多 8 个，首页展示前 4 个。
- 命令面板：`Ctrl/Cmd+K` 打开；输入即搜；↑↓ 选择、Enter 打开、Esc 关闭。
- 排序：按 manifest `order`，再按中文名排序；新增工具缺省排后。
- 文件拖入：接受文件的工具页支持把本地文件拖到页面载入，只读当前 File，不写入存储；未接入文件的页面统一拦截拖放，避免 WebView 直接打开文件替换页面。
- 空态：无匹配时给出明确提示。

**验收**：新增一个插件目录后，重启 dev server 即出现在首页，无需修改任何全局文件。

### 4.2 格式美化（JSON / XML / HTML / SQL）

**能力**

- 一个工具覆盖 JSON、XML、HTML、SVG、SQL；模式可选自动 / JSON / XML / HTML / SQL。自动模式以 `{` / `[` 开头识别 JSON，以 SELECT / INSERT / UPDATE / DELETE / WITH / CREATE 等开头识别 SQL，其余按 `<?xml`、DOCTYPE 与根元素推断标记语言；SVG、RSS、带命名空间的根元素按 XML 处理。
- 格式化：2 空格 / 4 空格 / Tab 缩进；标签、属性、注释、CDATA、DOCTYPE、处理指令按原样保留。
- SQL 格式化：关键字大写、子句换行、括号缩进；字符串、引号标识符与注释原样保留；压缩为单行。
- 压缩：JSON 输出单行；标记去掉标签之间的格式化空白，HTML 文本按空白折叠规则处理，行内元素之间保留一个空格。
- JSON 键名排序：递归、按码位比较、稳定排序、重复键保持相对顺序；仅在 JSON / 自动模式显示该选项。
- 语法高亮：JSON 分键名、字符串、数字、布尔、null、标点；标记分标签、属性、字符串、注释、声明；SQL 分关键字、字符串、数字、注释、运算符；输出超过 200,000 字符时关闭高亮。
- 树形视图：JSON / XML / HTML 结果可切换「文本 / 树」，节点可逐级展开收起；树节点与格式化文本 hover 联动，悬停任一节点会高亮对应输出片段并选中原文范围。
- 错误定位：错误码、行、列、字符、所在行文本。
- 统计：模式、行数、字符数、UTF-8 字节数；标记模式另含标签数。
- 操作：示例（按模式载入 JSON / XML / HTML / SQL）、清空、复制输出、`Ctrl+Enter` 运行、输入 Tab 插入当前缩进、拖入文本文件后切到自动模式并立即格式化。

**JSON 正确性边界（必须保持）**

- 保留数字原始字面量：`12345678901234567890`、`1.0`、`1E+3`、`-0.5` 原样输出，不经过 `JSON.parse` 的双精度。
- 保留字符串原始转义：`\u00e9`、`\n`、`\"` 不改写。
- 保留重复键。
- 拒绝：空内容、非法字符、未闭合字符串、非法转义、非法数字、缺冒号/逗号、尾逗号、结束后多余内容。
- 嵌套上限 200 层；超过返回 `tooDeep`。
- 空对象/空数组保持 `{}` / `[]` 单行。

**标记正确性边界**

- XML 严格校验：标签必须成对、闭合顺序必须匹配；未闭合、错配、多余闭合标签都返回错误。
- HTML 容错：识别空元素（`br`、`img`、`input`、`meta`、`link` 等）；允许省略 `li` / `p` / `dt` / `dd` / `tr` / `td` / `th` / `option` 等结束标签；块级元素开始会隐式闭合 `<p>`。
- `script` / `style` / `textarea` / `pre` 的内容原样保留，不重新缩进、不改写 `<` 与引号。
- 带文本的混合内容保持行内（如 `<p>Hello <b>world</b>!</p>`），不因为格式化插入额外空白；纯元素容器按层级展开。
- 属性值中的 `>` 不会被误判为标签结束；引号内的内容不参与结构解析。
- 输入上限 2,000,000 字符，嵌套上限 500 层。
- 错误码：`empty`、`tooLarge`、`tooDeep`、`unterminatedComment`、`unterminatedCdata`、`unterminatedTag`、`unterminatedDeclaration`、`invalidTag`、`unclosedTag`、`mismatchedTag`、`strayCloseTag`。

**运行时**：Worker；输入只参与当前计算，不写 localStorage。

### 4.3 字符编码转换

**格式**

Unicode 转义、HTML 实体、URL、Base64、UTF-8 字节（HEX）。

**能力**

- 编码 / 解码双向切换；一键交换输入输出并反转方向。
- 输入防抖 120ms 实时转换。
- 逐字码位表：字符、码位（U+XXXX）、十进制、UTF-8 字节、HTML 实体；最多 500 字，超出提示。
- 统计：字符数、UTF-8 字节数。
- 复制结果。

**正确性边界**

- Unicode 编码只转非 ASCII；非 BMP 字符输出 UTF-16 代理对（如 `😀` → `\uD83D\uDE00`）。
- Unicode 解码接受 `\uXXXX`、`\u{XXXXX}`、`U+XXXX`（含多个 `U+` 连写）；不符合模式的原样保留。
- HTML 实体：`& < > " '` 用命名实体，其余非 ASCII 用十进制数字实体；解码支持 `&#123;`、`&#x7B;`、常见命名实体与 `&nbsp;`；未知实体原样保留。
- URL：`encodeURIComponent` / `decodeURIComponent`；非法编码返回 `invalidUrl`。
- Base64：按 UTF-8 字节编码；分块避免大文本参数上限；解码忽略空白、允许省略末尾 `=`；非法返回 `invalidBase64`。
- HEX：编码输出空格分隔大写；解码接受空格/逗号/换行、`0x`、`\x`、连续写法；奇数位或非法字符返回 `invalidHex`。
- 逐字表始终描述“语义文本”：编码时看原输入，解码时看还原结果。

**运行时**：主线程。

### 4.4 进制转换

**能力**

- 源进制 / 目标进制：2–36。
- 常用进制快捷：2、8、10、16、36 一次展示。
- 输入实时转换（60ms 防抖）。
- 结果表：每个目标进制的值、是否精确；近似值标记 `≈`。
- 位宽统计；目标进制结果高亮。
- 每个结果可复制。
- 支持小数、正负号、空格/下划线、`0x`/`0b`/`0o` 前缀（仅进制匹配时剥离）。

**正确性边界**

- 整数用 BigInt 精确计算，超过 2^53 不丢精度。
- 小数按目标进制逐位乘取整，最多 16 位；除不尽标记近似并去掉末尾 0。
- `0.1₁₀ → 二进制` 必须标记近似；`10.5₁₀ → 1010.1₂` 精确。
- 错误：空输入、超长（2000 字符）、多个小数点、数字超出进制范围（指出具体字符与进制）、进制越界。
- 负零输出 `0`，不带负号。

**运行时**：主线程。

### 4.5 网络报文解析

**能力**

- 输入形态自动识别：连续 HEX、空格/逗号/冒号分隔、Wireshark/xxd 风格带偏移与 ASCII 列的转储、UTF-8 文本；也可手动指定“十六进制 / 文本”。
- 左侧报文原文与 ASCII 按输入行一一对应：每行上方为原文（HEX 按字节分隔或文本），下方为该行 ASCII；分行不重排为固定宽度。
- 右侧自动识别协议并逐字段给出名称、值、偏移与长度：Ethernet II、802.1Q / QinQ VLAN、ARP、IPv4、IPv6（含常见扩展头）、TCP、UDP、ICMP / ICMPv6、DNS、HTTP、TLS 记录。
- 字段悬停显示取值与含义；点击字段可固定说明。悬停左侧字节会高亮该字节并定位到所属字段。说明文案随中英文切换。
- 协议栈以 `›` 串联展示（例如 `Ethernet II › IPv4 › TCP › HTTP`）；无法识别时回退为“原始数据”并提示。
- 自动校验 IPv4 首部校验和、ICMP / ICMPv6 校验和，失败时在含义中标注；IPv4 分片、报文截断、长度字段越界会给出告警而不抛裸异常。
- 应用层：按端口与载荷识别 DNS（含压缩域名、常见 A/AAAA/CNAME/NS/PTR/MX/TXT 记录）、HTTP 首行与头部、TLS 记录头；其余显示 ASCII 负载预览。
- 高级区保留字段模板、逐字节视图与 SUM8 / XOR8 / SUM16 / CRC16-MODBUS 校验值；字段模板每行“字段名 + 分隔符 + 字节数”，支持 `#` 注释与单位“字节/B/bytes”，无效行按行号提示。
- 上限 65,536 字节；超出返回 `tooLong`。ASCII 中空格显示 `␠`，不可见字符显示 `·`。

**验收**

- 以太网 + IPv4 + TCP + HTTP 样例识别为 `Ethernet II › IPv4 › TCP › HTTP`，请求行与 `Host` 字段值正确。
- 裸 IPv4 + UDP + DNS 查询能解析出 `www.example.com`；IPv6 地址按最长零段压缩显示。
- 输入分行数与 ASCII 行数一致；IPv4 首部校验和正确时含义显示“校验通过”。
- 错误输入分别返回 `invalidHex` / `oddHex` / `tooLong`。

**运行时**：主线程。

### 4.6 子网计算

**能力**

- 输入 IPv4 与掩码/前缀；支持 `192.168.1.10/24` 内联前缀。
- 掩码接受 `24`、`/24`、`255.255.255.0` 三种写法。
- 滑块选择前缀 0–32，与掩码输入双向同步。
- 结果卡片：网络地址/CIDR、广播地址、首个可用、最后可用、掩码、通配符、可用主机数、地址总数、地址类型。
- 二进制对照：地址（网络位与主机位用竖线分隔）、网络地址、广播地址。
- 地址类型：PRIVATE / SHARED(CGNAT) / LOOPBACK / LINK_LOCAL / MULTICAST / RESERVED / PUBLIC。
- 每项可复制。
- 输入实时计算（90ms 防抖）。

**正确性边界**

- `/0`、`/16`、`/24`、`/30`、`/31`、`/32` 的主机数口径：`/0–/30` 扣网络与广播；`/31` 两点都可用；`/32` 单机可用。
- 非连续掩码（如 `255.0.255.0`）返回 `maskNonContiguous`。
- 每段必须是 0–255 的十进制；段数不足、越界、非数字返回 `ipInvalid`。
- 位运算必须用 `>>> 0` 保持 32 位无符号。

**运行时**：主线程。

### 4.7 JWT 与密钥

- 四个页签：解码、验签、密钥、加解密。
- 解码：拆出 header / payload / signature，展示 iat / nbf / exp 状态；不自动信任令牌内容。
- 验签：HMAC（HS256/384/512，密钥）与 RSA/ECDSA（RS256/384/512、ES256/384/512，PEM 或 JWK 公钥）。
- 密钥：生成 RS/ES 密钥对，输出 PEM（PKCS8/SPKI）、JWK 与公钥 SHA-256 指纹；支持 PEM ↔ JWK 互转。
- 加解密：AES-GCM 256 + PBKDF2-SHA256（100k），输出 Base64（salt|iv|cipher）。
- 令牌、密钥、口令与明文只在内存中，不写入 localStorage。
- 错误码：`empty`、`tooLong`、`invalidToken`、`invalidJson`、`invalidAlg`、`invalidSecret`、`invalidKey`、`invalidPassword`、`badPayload`、`cryptoUnavailable`。
- 运行时：主线程。

### 4.8 哈希与校验

- 算法：MD5、SHA-1、SHA-256、SHA-384、SHA-512、CRC32；可多选，默认 MD5 + SHA-256。
- 文本按 UTF-8 编码，上限 1,000,000 字符；空串也是合法输入。
- 输出 HEX 或 Base64；每个算法单独展示并逐条复制。
- 文件模式：选择文件后对同一组算法计算摘要，上限 64 MB；文件不离开设备；拖入文件时自动切到文件模式。
- HMAC：填写密钥后只保留 SHA 系列，MD5/CRC32 自动跳过；密钥不落盘、不回显。
- 期望值：粘贴摘要后忽略大小写比对，命中/不命中明确标识。
- MD5/SHA-1 显示“不适合安全用途”提示。
- 错误码：`invalidAlgorithm`、`noAlgorithm`、`tooLong`、`cryptoUnavailable`、`fileTooLarge`。
- 运行时：Worker（文本）；文件模式在主线程读取后调用同一核心。

### 4.9 时间工具箱

- 四种模式：时间戳、日期差、日期加减、Cron。
- 时间戳：输入 Unix 秒/毫秒或 ISO 8601 日期；自动模式按 10/13 位区分秒与毫秒，也可强制单位。
- 输出 Unix 秒、毫秒、ISO 8601、UTC、所选时区与本机时间。
- 时区：IANA 列表，默认本机；夏令时交给 `Intl`；非法时区返回 `invalidTimeZone`。
- 日期差：两行输入，拆分天/时/分/秒并给出总时长；两行都支持时间戳或日期字符串。
- 日期加减：分钟/小时/天/周/月/年；月份按日历语义并夹到目标月末。
- Cron：5 段或 6 段（秒），支持 `*`、`*/n`、`a-b`、列表与月份/星期缩写；显示未来 1–20 次执行；按浏览器本地时区求值，时区选择只影响展示。
- Cron 可视化生成：按「每 N 分钟 / 每小时 / 每天 / 每周 / 每月」选择频率与间隔、星期、日、时、分，实时生成表达式并填入输入框；自定义模式仍可直接编辑表达式。
- 兼容旧行为：默认模式为时间戳转换，结果保留 `milliseconds` 字段。
- 错误码：`empty`、`tooLong`、`invalidInput`、`outOfRange`、`invalidTimeZone`、`invalidAmount`、`invalidUnit`、`invalidCron`、`cronNoMatch`、`diffEmpty`。
- 运行时：主线程。

### 4.10 随机生成器

- 类型：密码、PIN、UUID v4/v7、ULID、NanoID、随机字节、随机整数、抽取、洗牌、分组。
- 密码：长度 4–128，可选大小写/数字/符号，可排除易混淆字符并保证每类至少一个；显示熵（bits）与强度档位。
- 批量上限 200；随机字节单条 1–1024 B，支持 HEX / Base64。
- 随机整数：最小/最大值，可选不重复；区间不足时返回可读错误。
- 抽取/洗牌/分组：每行一个条目；抽取数量不超过条目数，分组数介于 2 与条目数之间。
- 全部随机数来自 Web Crypto，缺失时报错，不退回 `Math.random`。
- 错误码：`invalidMode`、`invalidCount`、`invalidLength`、`noCharset`、`lengthTooShort`、`cryptoUnavailable`、`invalidRange`、`rangeTooSmall`、`notEnoughItems`、`invalidAlphabet`、`invalidGroupCount`。
- 运行时：主线程。

### 4.11 UUID 生成

- 输入为空时批量生成 UUID v4（1–100 个）；输入非空时解析版本与变体。
- 选项：数量、大写、是否保留连字符。
- 随机源优先 `crypto.getRandomValues`，缺失时回退 `Math.random`。
- 错误码：`invalidCount`、`invalidUuid`。
- 运行时：主线程。

### 4.12 URL 解析

- 拆解 protocol、username、password、host、hostname、port、pathname、search、hash、origin。
- 查询参数保留顺序与重复键，同时给出解码值与原始值；`+` 按空格解码。
- 需要完整协议；相对 URL 返回 `invalidUrl`。
- 错误码：`empty`、`tooLong`、`invalidUrl`。
- 运行时：主线程。

### 4.13 正则测试

- 正则与 flags 独立输入；flags 允许 `dgimsuy`，未写 `g` 时内部补全以展示全部匹配。
- 输出匹配索引、匹配值、普通捕获组与命名组；最多 500 条并标记截断。
- 支持替换预览（`$1`、命名引用等）。
- 测试文本上限 20,000 字符，降低灾难性回溯影响。
- 错误码：`emptyPattern`、`invalidPattern`、`invalidFlags`、`tooLong`、`invalidReplacement`。
- 运行时：主线程。

### 4.14 文本清洗与对比

- 五种模式：清洗、统计、命名转换、表格、行级对比。
- 统计：字符（按码位）、行数、单词（英文词 + 中文连续段）、中文字数、UTF-8 字节数。
- 清洗：去首尾空白、删空行、去重、倒序、行号、按原序/升/降/长度排序、全角↔半角、前后缀与合并符。
- 命名转换：一次输出 camelCase / PascalCase / snake_case / kebab-case / CONSTANT_CASE。
- 表格：CSV / TSV / 竖线分隔 → Markdown（左/中/右对齐），也支持 Markdown → CSV；首行为表头。
- 对比：Myers 行级 diff，可忽略空白或大小写，最多 2000 行。
- 输入上限 1,000,000 字符；错误码：`empty`、`tooLong`、`tooManyLines`。
- 运行时：主线程。

### 4.15 颜色与前端设计

- 输入 HEX / RGB(A) / HSL(A)，输出 HEX、RGB、HSL、HSV、LAB 与 CSS 变量片段。
- 对比度：对白底与黑底的 WCAG 对比度，标注 AA / AAA。
- 配色：互补、邻近、三角、分裂互补、四角配色；点击色块回填输入。
- 不做色彩管理，统一按 sRGB / D65；错误码：`invalidColor`。
- 运行时：主线程。

### 4.16 单位换算

- 类别：长度、面积、体积、重量、速度、压力、数据量、时间、温度。
- 输入数值后给出目标单位结果，并列出该类别全部单位的换算表，可逐条复制。
- 温度使用单独公式；其余按静态基准系数换算。
- 结果保留 6 位有效数字；错误码：`invalidNumber`、`unknownUnit`。
- 运行时：主线程。

### 4.17 文件工具

- 三种模式：识别、打包、解包。
- 识别：读取前 64 字节 magic bytes，识别图片、压缩包、音视频、可执行文件、字体、数据库、WebAssembly 等；同时计算整文件 SHA-256。
- 打包：多选文件，重名自动改名为 `a(1).txt`；合计上限 200 MB，使用 fflate 生成 ZIP（level 6）。
- 支持把文件拖入页面；打包模式一次接收拖入的多个文件，识别与解包取第一个。
- 解包：读取 ZIP 条目，逐个下载；不执行压缩包内内容。
- 文件只在本机读取，不上传；错误码：`empty`、`invalidHex`。
- 运行时：主线程（`File` 无法跨 Worker 传递）。

### 4.18 图片工具

- 三种模式：压缩、ICO、EXIF。
- 压缩：按最大宽度等比缩放，输出 PNG / JPEG / WebP / 跟随原格式，质量 10–100；显示前后体积与节省比例，可下载或复制 Data URI。
- ICO：从 16/32/48/64/128/256 中多选尺寸，居中裁切后打包为 `.ico`。
- EXIF：解析 JPEG APP1/EXIF，展示常用 IFD 标签；非 JPEG 返回 `notJpeg`。
- 单图上限 30 MB；图片只在本机处理；支持把图片拖入页面。
- 运行时：主线程（Canvas / DOM）。

### 4.19 运维速查

- 按域分组：systemd、Nginx、Docker、MySQL、SSH 等；内置常用端口、HTTP 状态码、MIME 与 Nginx 片段速查。
- 支持关键词搜索与域过滤；危险命令标记并在复制前二次确认。
- 静态数据，不连接任何服务；运行时：主线程。

### 4.20 PDF 转换

- 三种模式：PDF → 图片、图片 → PDF、PDF → 文字。
- PDF → 图片：页码范围（留空全部、`1-3,5`、`3-`），PNG / JPEG，标准/高清/超清，单次最多 200 页；可单张下载或打包 ZIP。
- 图片 → PDF：多图排序（最多 100 张），页面 A4 / A4 横向 / 跟随图片，可设页边距；输出最小 PDF 1.4。
- PDF → 文字：逐页提取文字，按页分隔，支持复制或下载 `.txt`。
- PDF 渲染 / 取文字使用 `pdfjs-dist`（按需动态加载），ZIP 与图片 PDF 为内置实现；文件不上传。
- 运行时：主线程；pdfjs 在工具打开后才加载，不进入入口 chunk。

### 4.21 数据格式转换

- 两种模式：转 JSON（YAML / TOML / INI / .env / Properties / JSON → JSON）、从 JSON 转出（JSON → 目标格式）。
- 源格式可选自动 / YAML / TOML / INI / .env / Properties / JSON；自动识别以 `{` / JSON 数组形态识别 JSON，`[section]` + `=` 区分 TOML / INI，`---` 或 `key:` 识别 YAML，大写键识别 .env，含 `\uXXXX` 或点号键识别 Properties；无法判断返回 `unsupportedFormat`，不猜测。
- 选项：缩进 2 / 4 / Tab；INI `flatten`（递归展开为点号键，关闭时顶层为节）；键名排序。
- 解析结果统一归一化为普通对象/数组/标量；拒绝 `__proto__`、`constructor`、`prototype`。
- YAML：别名上限 100，多文档返回 `multiDocument`，循环锚点返回 `cyclicReference`，日期保持字符串。
- TOML：日期/时间归一化为 ISO 字符串；`nan` / `inf` 输出为字符串并给 `nonFiniteNumber`。
- INI：支持 `;` / `#` 注释、节、`=` / `:` 分隔、重复键后者覆盖；数组与深层嵌套按 `flatten` 规则处理。
- Properties：支持 `\uXXXX`、续行、`=` / `:` 分隔；输出点号键并转义特殊字符。
- .env：支持 `export`、单双引号、注释；只接受扁平标量对象，键名须匹配 `^[A-Za-z_][A-Za-z0-9_]*$`。
- 输入上限 1,000,000 字符，嵌套上限 100；错误码：`empty`、`tooLarge`、`tooDeep`、`syntaxError`、`unsupportedFormat`、`multiDocument`、`tooManyAliases`、`cyclicReference`、`unsafeKey`、`nestedNotSupported`、`invalidKey`、`unsupportedValue`。
- 警告：`nonFiniteNumber`、`commentsDropped`、`precisionLoss`、`duplicateKey`；注释解析后丢弃。
- 运行时：Worker；`yaml` 与 `smol-toml` 在需要时动态加载，不进入工具入口 chunk。
- 支持把文本文件拖入页面：切到转 JSON + 自动识别源格式后立即转换。

### 4.22 HTTP 报文

- 两种模式：解析原始报文、从 JSON 描述生成报文。
- 解析：起始行、头部、Cookie / Set-Cookie、查询参数、正文；支持 `\r\n` / `\n`、重复头、obs-fold、chunked 扩展与 trailer。
- 正文按 `Content-Length` 截取；同时存在 `Transfer-Encoding` 与 `Content-Length` 时以 chunked 为准并警告。
- `application/json`、`x-www-form-urlencoded`、`multipart/form-data` 分别展开；`gzip` / `br` / `deflate` 不解压，标为 binary 并给十六进制预览。
- 生成：请求需 `method` + `target`，响应需 3 位 `status`；头值不得含 CR/LF；可自动补 `Content-Length`；`chunked=true` 时输出单块与结束块。
- 只支持 HTTP/1.0 / 1.1 明文；HTTP/2 前言与 HTTP/3 返回 `unsupportedVersion`。
- 输入上限 1,000,000 字符、头部上限 500。
- 错误码：`empty`、`tooLarge`、`invalidStartLine`、`unsupportedVersion`、`invalidHeader`、`tooManyHeaders`、`invalidContentLength`、`truncatedBody`、`invalidChunk`、`unsupportedTransferEncoding`、`invalidBuildInput`。
- 警告：`mixedLineEndings`、`obsoleteLineFolding`、`conflictingLength`、`lengthMissing`、`contentEncodingNotDecoded`、`invalidJsonBody`、`invalidMultipart`、`binaryBody`、`invalidPercentEncoding`。
- 运行时：Worker；Cookie、Authorization 与正文只在当前页面内存，不写 localStorage，不发网络请求。

### 4.23 cURL 转换

- 只做 cURL → 代码，目标为 fetch / axios / Python / Go / PowerShell。
- shell 词法：单引号字面量、双引号转义、ANSI-C `$'...'`、反斜杠续行、短选项簇（`-sS`、`-kL`、`-XPOST`、`-H'...'`）。
- 支持方法、头、正文、`--data-urlencode`、`-F` 表单、`-G` 查询、Basic 认证、Cookie、UA/Referer、压缩、TLS、重定向；代理/证书选项给出警告。
- `-d` 多值按 `&` 拼接；有 `-d` / `-F` 且无 `-X` 时默认 POST；默认不跟随重定向（与 cURL 一致）。
- 未知选项不猜测是否带值，记警告后继续；找不到 URL 返回 `invalidUrl`。
- `$VAR` 不展开，保留字面量并给 `unexpandedVariable`。
- 五目标都保证方法、URL、头与正文可复制；`-k` 在浏览器 fetch 下给出不可用说明，在其它目标给出对应写法。
- 输入上限 100,000 字符；错误码：`empty`、`notCurl`、`unterminatedQuote`、`missingValue`、`invalidUrl`、`invalidHeader`、`tooLong`。
- 运行时：主线程；不执行命令、不发网络请求、输入不落盘。

### 4.24 IP 段计算

- 四种模式：合并（`merge`）、范围互转（`range`）、包含判断（`contains`）、排除（`exclude`）。
- 输入每行一个 CIDR / IP / `start-end`；空行与 `#` 注释忽略；上限 10,000 行。
- IPv4 32 位、IPv6 128 位 BigInt 运算；同一次计算不能混合 family。
- 合并与排除输出最小 CIDR 集，按地址升序；CIDR 主机位归一到网络地址；IPv6 输出 RFC 5952 风格压缩。
- `contains` 与 `exclude` 以第一行为基准段，后续行为测试地址或排除子段。
- 错误码：`empty`、`invalidAddress`、`invalidPrefix`、`invalidRange`、`mixedFamily`、`tooMany`。
- 运行时：主线程。

### 4.25 MQTT 主题

- 三种模式：解析（`parse`）、匹配（`match`）、校验（`validate`）。
- 层级按 `/` 分隔，空层级合法；`+` 必须独占一层，`#` 必须独占最后一层。
- 共享订阅 `$share/{group}/{filter}`；group 不能为空、不能含 `/`、`+`、`#`。
- 首层 `#` / `+` 不匹配 `$` 开头的系统主题；发布主题不能含通配符。
- `match` 以第一行为过滤器，后续行为具体主题；`validate` 每行同时报告过滤器与发布主题是否合法。
- `#` 是合法通配符，因此本工具不提供注释行。
- 单主题上限 65,535 字节；错误码：`emptyTopic`、`emptyFilter`、`invalidWildcard`、`invalidShared`、`publishWildcard`、`tooLong`。
- 运行时：主线程；不连接 broker。

### 4.26 设置

- 主题：深色 / 浅色，持久化，跟随首次系统偏好。
- 语言：中文 / English，持久化；切换后清单与 UI 立即更新。
- 隐私说明：明确“输入不上传、不落盘”。
- 数据：清除最近使用；清除全部本地数据（含主题/语言/收藏/选项，刷新生效）。
- 关于：版本号（`VERSION` 注入）、运行形态（Web/PWA、桌面、移动）、插件机制。
- 快捷键说明。
- 用户插件：导入 JavaScript 文件（或下载示例）后立即注册；支持导出、删除；不提供内置编辑器；坏插件单独列出，可删除。

### 4.27 插件平台

- 目录约定自动注册；清单校验；构建期 `npm run check:plugins` 闸门。
- 脚手架 `npm run plugin:new` 生成五件套。
- 统一 `run` 契约与 `ToolResult` 错误格式。
- main/worker 运行时选择；Worker 超时、回退、序号守卫。
- 共享 UI 组件与 core API。
- 插件开发指南与评审清单。
- 运行时用户插件：代码以函数体形式保存在本机 localStorage，启动时编译成 `{ manifest, run }` 注册；与内置插件共用列表、搜索、收藏、最近使用和 `/t/:id` 路由。
- 用户插件契约：固定主线程；`run` 可同步或异步；返回值收敛为标准 `ToolResult`；错误码以 `PLUGIN_*` 开头。
- 用户插件边界：单插件 ≤ 64KB、最多 32 个、id 不得与内置工具冲突；不做网络上传或自动下载；以页面权限运行，无沙箱。

## 5. 平台要求

### 5.1 Web / PWA

- 静态托管即可运行；hash 路由。
- 可安装到桌面/主屏；离线打开核心工具。
- 非安全上下文剪贴板回退。

### 5.2 Desktop

- Tauri 2；Windows/macOS/Linux。
- 全局快捷键 `Ctrl+Shift+B` 显示/隐藏窗口。
- 单实例；重复启动聚焦已有窗口。
- 图标、窗口尺寸、最小尺寸按 `tauri.conf.json`。
- **软件更新**：`tauri-plugin-updater` + Ed25519 签名。启动 8 秒后自动检查、之后每 24 小时一次；设置页可手动检查、下载、安装。
  - 更新源默认 ihomy 镜像，可切 GitHub Releases；切换后下一次检查立即生效。
  - 「自动更新」默认关闭：开启后发现新版本即自动下载；Windows 在空闲 10 分钟后自动安装，免安装版另在下次启动时安装，其它平台在下次启动时安装。
  - 安装版只接受 NSIS 包并装回注册表记录的原目录；免安装版只接受清单里的 `windows-x86_64-portable` 裸 exe 并原位替换。两种形态绝不交叉。
  - 已下载的包与 `pending.json` 落在 `app_data_dir/updates/`，重启后恢复「待安装」。

### 5.3 Mobile

- Tauri 2 Android/iOS；响应式布局、底部导航、安全区。
- 触控目标 ≥ 34px；输入法弹出时工具区可滚动。
- 不编译桌面专属插件（`#[cfg(desktop)]`）。

### 5.4 发布与分发

- **出包**：`.github/workflows/release.yml` 以 `v*` tag 触发，三平台矩阵构建：
  - Windows：NSIS 安装版 + 免安装 zip（矩阵带 `--target x86_64-pc-windows-msvc`，产物在 `target/<triple>/release`）。
  - Linux：deb + AppImage。
  - macOS：universal dmg（arm64 + x86_64，未签名 / 未公证）；应用内更新需代码签名后才生效。
  - Web/PWA：`npm run build` 的 `dist/` 打成 `_web.zip`。
- **发布形态**：所有产物进同一个 GitHub **draft** Release，人工确认后 Publish；不自动发布。
- **产物命名**：`bit_pouch_<版本>_x64-setup.exe` / `_x64-portable.zip` / `_x64-portable.exe` / `_amd64.deb` / `_amd64.AppImage` / `_universal.dmg` / `_web.zip`。
- **签名与清单**：`bundle.createUpdaterArtifacts` 产出各平台 `.sig`；`tauri-action` 汇总生成 `latest.json`，Windows 额外补 `windows-x86_64-portable` 条目指向签过名的裸 exe。`requireSignedVersion` 要求签名 trusted comment 带版本号，tauri-cli 必须 ≥ 2.12.1。
- **校验**：`npm run verify:release` 校验 `VERSION`（`V<主>.<次>`）、`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 的版本一致；CI 的 `verify` job 再拉取 Release 资产、`latest.json` 与全部 `.sig`，确认资产齐全、平台条目与签名一一对应、签名 key id / 版本号正确。
- **分发**：ihomy 发布页 `https://ihomy.top/bit-pouch`（`/bit-pouch`，alias `/bit_pouch`）统一指向 `https://ihomy.top/files/bit_pouch/<文件名>`；服务器由 `scripts/ihomy-mirror/` 的 systemd 定时器每日从 GitHub `/releases/latest` 同步（天然排除 draft / prerelease），先落安装包与 `.sig`、最后原子替换 `release.json` 与 `updates/latest.json`，旧版本只增不删。GitHub Releases 作为备用入口。每个资产按 GitHub API 的 sha256 digest 校验；直连被限速/中断时经可配置加速前缀下载（失败或校验不过自动回退直连），代理只搬字节、不参与信任链。
- **应用内更新**：默认读 `https://ihomy.top/files/bit_pouch/updates/latest.json`，设置页可切 GitHub Releases。镜像只改写清单里的 URL，`signature` 原样保留；客户端用内嵌公钥校验，签名不符直接拒装。检查 / 下载 / 安装三阶段由 Rust 状态机推进，前端只渲染。
- **安全边界**：镜像只搬文件、改写 URL，不改签名；nginx 对 `/files/` 静态直出补 `X-Content-Type-Options: nosniff` 与 HSTS；当前仍无代码签名证书，发布页明确提示 Windows SmartScreen / macOS 首次打开方式。

| 版本 | 主题 | 候选工具/能力 |
|------|------|--------------|
| V0.2 | 工程常用 | JWT 解析、Hash（MD5/SHA）、时间戳、UUID、URL 解析、正则测试 |
| V0.3 | 工具箱同步 | 哈希与校验（CRC32/HMAC/文件摘要）、时间工具箱（时区/日期差/Cron）、随机生成器 |
| V0.4 | 工具补齐 + 用户插件 | 文本清洗与 Diff、颜色、单位、文件 ZIP、图片/ICO/EXIF、运维速查、PDF 转换、JWT 验签/密钥/加解密、统一格式化（JSON / XML / HTML）；本地用户插件（导入 JavaScript 文件，运行时注册） |
| V0.5 | 格式与协议 | 数据格式转换（YAML / TOML / INI / .env / Properties ↔ JSON）、HTTP 报文解析与生成、cURL 转 fetch / axios / Python / Go / PowerShell、IP 段合并与排除、MQTT 主题校验与匹配；实时 HTTP 客户端与 WebSocket 调试因需联网另立项目 |
| V0.6 | 平台能力 | 网络报文自动识别与字段详解（Ethernet / IP / TCP / UDP / DNS / HTTP / TLS）；文件拖入；多窗口/悬浮窗、插件分组与快捷键自定义 |
| 后续 | 生态 | 插件市场（签名+权限）、用户插件分组与隔离、WASM 加速 |

## 10. 风险与待决

- Tauri 移动端真机未验证；剪贴板/输入法/滚动需回归。
- 全局快捷键可能与系统或其他应用冲突，后续提供自定义。
- 本地用户插件已支持，但以页面权限运行、无沙箱；对外分发或做插件市场前，必须先定义签名、权限、隔离与版本兼容。
- 许可证未定；对外分发前需明确。
