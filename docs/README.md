# bit_pouch 文档索引

> 一页地图：每份文档一句话定位。新会话从 `AGENTS.md` 开始，不要通读全部。

## 开始工作

1. `AGENTS.md` —— 规则、任务路由、代码地图、验证基线（自动加载）。
2. `docs/现状.md` —— 版本、在途、下一步、当前基线、已知问题。
3. `docs/工具索引.md` —— 24 个工具的 id / 分类 / 运行时 / 文件 / 测试 / README（脚本生成）。
4. 按 `AGENTS.md` §2 的路由表读对应文档。

## 维护规矩

- 文档分工、归档流程、计数口径统一见 `AGENTS.md` §9 与 `archive` 技能；本页只维护索引。
- 新增 / 删除 `docs/` 根目录文档时必须更新本页；`npm run docs:check` 会校验遗漏、链接和工具数。
- `docs/工具索引.md` 由 `npm run docs:index` 生成，禁止手改。
