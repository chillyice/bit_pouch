- **插件自动发现**：`import.meta.glob` 代替手写工具数组与逐工具路由；新增工具零全局改动。

- **不引 UI 库**：自建设计系统，控制体积与跨端一致性。
- **hash 路由**：静态托管、Tauri、移动端零配置。
- **输入不持久化**：只存选项/收藏/最近/主题/语言；隐私优先。
- **版本**：`VERSION` 为 `V0.1`；Tauri semver 为 `0.1.0`。

**文件级改动**

| 文件/目录 | 改动 |
|-----------|------|
| `src/plugins/jwt/*` | 只读解析 header/payload/signature，exp 状态与剩余时间 |
| `src/plugins/hash/*` | MD5（RFC 1321 内置）+ SHA-1/256/384/512（Web Crypto），HEX/Base64 |

| `src/plugins/uuid/*` | v4 批量生成（1–100）、版本/变体解析、大小写与连字符选项 |
| `src/plugins/url/*` | URL 组件拆解、查询参数顺序/重复键/原始值 |
| `src/plugins/regex/*` | 匹配/捕获组/命名组、替换预览、500 条截断 |
| `src/components/ToolIcon.vue` | 新增 key/hash/clock/fingerprint/link/regex 图标映射 |
| `src/App.vue` / `src/views/SettingsView.vue` | 版本号改为 script 常量引用，修复模板中 `__APP_VERSION__` 不注入的问题 |

| `VERSION` / `package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml` | 版本进位 V0.2 / 0.2.0 |
| `docs/需求设计说明书.md` | 新增 §4.7–4.12，设置/插件平台顺延为 §4.13/§4.14 |
| `docs/迁移映射.md` | 记录 JWT 迁移与 5 个新增工具的来源差异 |

**关键决策**

- Hash 放 Worker：大输入摘要不阻塞 UI；SHA 走 Web Crypto，避免引第三方加密库。
- MD5 自写并覆盖 RFC 1321 向量；界面明确提示 MD5/SHA-1 不适合安全用途。
- JWT 只解码不验签，签名段按原文长度展示，避免误导为“已验证”。
- 正则输入上限 20,000 字符、匹配上限 500 条，降低灾难性回溯与渲染压力。
- UUID 随机源优先 `crypto.getRandomValues`，缺失时回退 `Math.random`（仅影响生成质量）。
- 所有新工具只持久化选项（算法、单位、数量、flags），输入/令牌/URL/正则均不落盘。

**关键决策**

- **发布入口是 tag，不是本机打包**：`v<版本>` tag 触发矩阵构建，三平台产物统一进同一个 draft Release；人工确认后 Publish。
- **版本四处对齐**：根 `VERSION`（`V0.2`）、`package.json`（`0.2.0`）、`tauri.conf.json`、`Cargo.toml` 主次必须一致；`verify:release` 与 CI 的 `verify` job 双重把关。
- **产物命名固定**：`bit_pouch_<版本>_{x64-setup.exe,x64-portable.zip,amd64.deb,amd64.AppImage,universal.dmg,web.zip}`，发布页与镜像都按这个名字拼 URL。
- **直链优先、GitHub 兜底**：发布页四个平台全部指向 `/files/bit_pouch/<文件名>`；服务器只搬文件、不改写。GitHub Releases 只作备用入口。
- **镜像排除草稿**：取 GitHub `/releases/latest`（天然排除 draft / prerelease），所以流程必须是「先 Publish 再改发布页版本号」。
- **不接自动更新**：当前没有 `tauri-plugin-updater`，因此不做 `.sig` / `latest.json`；页面明确写「下载新包覆盖安装」。
