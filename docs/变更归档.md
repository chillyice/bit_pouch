- **插件自动发现**：`import.meta.glob` 代替手写工具数组与逐工具路由；新增工具零全局改动。

- **不引 UI 库**：自建设计系统，控制体积与跨端一致性。
- **hash 路由**：静态托管、Tauri、移动端零配置。
- **输入不持久化**：只存选项/收藏/最近/主题/语言；隐私优先。
- **版本**：`VERSION` 为 `V0.1`；Tauri semver 为 `0.1.0`。

| 文件/目录 | 改动 |

| `docs/迁移映射.md` | 记录 JWT 迁移与 5 个新增工具的来源差异 |

**关键决策**

- Hash 放 Worker：大输入摘要不阻塞 UI；SHA 走 Web Crypto，避免引第三方加密库。
- MD5 自写并覆盖 RFC 1321 向量；界面明确提示 MD5/SHA-1 不适合安全用途。
- JWT 只解码不验签，签名段按原文长度展示，避免误导为“已验证”。
- 正则输入上限 20,000 字符、匹配上限 500 条，降低灾难性回溯与渲染压力。
- UUID 随机源优先 `crypto.getRandomValues`，缺失时回退 `Math.random`（仅影响生成质量）。
- 所有新工具只持久化选项（算法、单位、数量、flags），输入/令牌/URL/正则均不落盘。

**关键决策**

- **发布入口是 tag，不是本机打包**：`v<版本>` tag 触发矩阵构建，三平台产物统一进同一个 draft Release；人工确认后 Publish。
- **版本四处对齐**：根 `VERSION`（`V0.2`）、`package.json`（`0.2.0`）、`tauri.conf.json`、`Cargo.toml` 主次必须一致；`verify:release` 与 CI 的 `verify` job 双重把关。

- **函数体而非 ES 模块**：用 `new Function('"use strict"; ...')` 同步编译，兼容 `export default`，避免 Blob URL 动态 import 在 WebView/CSP 下的不确定性；不支持 `import`，插件必须自包含。
- **通用视图**：用户插件只提供 manifest + run，不加载任意 Vue 组件；界面统一由 `UserToolView` 承载，避免把 Vue 运行时暴露给插件代码。

- **同 id 覆盖**：导入相同 id 视为更新；id 不得与内置工具冲突，避免收藏/最近使用串味。
- **本地信任模型**：插件以页面权限运行，只面向“自己写、自己用”；不做上传、签名或市场。
- **坏插件不阻塞启动**：编译失败的记录只在设置页展示，可单独删除。
- **存储失败显式报错**：`writeJson` 返回是否成功；安装/删除写入 localStorage 失败时返回 `PLUGIN_STORAGE`，不把“本次会话可用、刷新后丢失”伪装成成功。

**关键决策**

- **不用 DOM 解析**：`DOMParser` 在 Worker 与部分 WebView 中不保证可用，且会把标记“规范化”后再序列化，丢失原始属性写法、注释位置与自闭合风格；自写词法器只重排空白，内容保持原样。
- **XML 严格、HTML 容错**：同一套解析器按模式切换策略。XML 报未闭合/错配/多余闭合；HTML 识别空元素、隐式闭合 `li` / `p` / `tr` / `td` / `option`，并按规范在块级元素前结束 `<p>`。
- **混合内容不拆行**：带文本的元素优先保持行内（`<p>Hello <b>world</b>!</p>`），只有纯元素容器才按层级展开，避免格式化在行内元素之间插入空白导致渲染变化。
- **原始内容保留**：`script` / `style` / `textarea` / `pre` 的内部文本完全原样输出，不解析其中的 `<`，也不重新缩进。
- **自动模式默认 HTML**：只有 XML 声明、非 HTML DOCTYPE、SVG/RSS/带命名空间根元素才判为 XML；HTML 片段直接粘贴即可格式化，不因未闭合标签报错。
