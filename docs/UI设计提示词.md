# bit_pouch UI 设计提示词

> 本文既是设计规范，也可作为重新生成界面的提示词。核心气质：**口袋工作台**——紧凑、可靠、有一点点硬件感，不喧哗。

## 1. 品牌与气质

- **名字**：bit_pouch（比特口袋）。像一个随时掏出来的工具袋，而不是一个 SaaS 控制台。
- **关键词**：工作台、精密、夜班、荧光标记、哑光金属、单色底 + 一个高亮色。
- **避免**：渐变紫、玻璃拟态堆叠、圆角过大、卡通插画、营销式大标题、Element Plus 默认观感。
- **情绪**：打开就想干活；信息密度高但不拥挤；深色为主，浅色是“日光工作台”。

### Logo 资产

- **造型**：荧光绿圆角方块 + 深色像素 `b_` 字标；`b_` 同时是侧栏品牌标记，图标与界面同源。
- **颜色**：底色 `#b8ff3d`，字标 `#142000`；横版字标深底 `#0a0d0b`，英文 `bit_pouch` 近白，中文名 `比特口袋` 荧光绿。
- **源文件**：`src-tauri/app-icon.svg`（1024 圆角 App 图标）、`src-tauri/app-icon-maskable.svg`（PWA maskable，80% 安全区）、`public/favicon.svg`（32×32）、`public/logo.svg`（420×128 横版字标）。
- **生成**：改完 SVG 源后跑 `npm run tauri icon src-tauri/app-icon.svg`；PWA PNG 从同一 32 网格整数倍重出；Android adaptive foreground 按 66dp 安全圆单独生成透明底 `b_`，背景色 `#B8FF3D`，不能直接用全幅图标。
- **字标**：`bit_pouch` 等宽粗体 + 中文名 `比特口袋`；中文名同时用于 HTML 标题、PWA `short_name`、Tauri 窗口标题与侧栏副标。
- **禁止**：加渐变、玻璃高光、3D 渲染、投影或描边；保持纯色方块与像素边缘。

## 2. 设计令牌

```css
:root {
  --bg: #0a0d0b;          /* 近黑，带一点绿 */
  --panel: #111814;
  --panel-2: #151f19;
  --panel-3: #1a2720;
  --line: #24332a;
  --line-strong: #354b3d;
  --text: #e7f0e9;
  --text-dim: #a0b3a6;
  --text-faint: #6f8578;
  --accent: #b8ff3d;      /* 酸性荧光绿，唯一主强调色 */
  --teal: #5eead4;        /* 次强调，用于 Worker/校验值 */
  --blue: #7dd3fc;        /* 数字 */
  --amber: #fbbf24;       /* 收藏 */
  --red: #fb7185;         /* 错误 */
  --radius: 13px;
  --mono: ui-monospace, "JetBrains Mono", "Cascadia Code", Consolas, monospace;
  --sans: ui-sans-serif, system-ui, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

浅色主题不是简单反色：底色偏暖纸白 `#f2f4ec`，主强调色压深为 `#5f9c00` 以保证对比度。

## 3. 字体

- 正文：系统无衬线；中文优先 PingFang / 微软雅黑。
- 数据：等宽字体；数字、HEX、JSON、报文一律等宽。
- 标题：字重 700，字距 `-0.03em`；不要使用装饰字体。
- 字号：正文 14px；工具数据 12.5px；元信息 10–11px；首页主标题 `clamp(26px, 3.2vw, 40px)`。

## 4. 布局

### 桌面（>900px）

```text
┌────────────┬──────────────────────────────────────────────┐
│ sidebar    │  page (max 1340px)                           │
│ 272px      │  eyebrow / h1 / sub                          │
│ brand      │  filter chips                                │
│ search     │  tool grid (auto-fill 236px)                 │
│ nav        │  …                                           │
│ categories │                                              │
│ recent     │                                              │
│ footer     │                                              │
└────────────┴──────────────────────────────────────────────┘
```

- 侧栏 `position: sticky; height: 100dvh`，背景半透明 + `backdrop-filter: blur(18px)`。
- 主区左右 padding 36px，底部 80px。
- 工具页：返回链接 → 标题行（图标 48px + 标题 + 徽标 + 收藏）→ 选项条 → 工作区。

### 移动（≤900px）

- 侧栏隐藏；顶部 sticky bar：品牌 + 搜索 + 主题。
- 底部固定导航：全部 / 收藏 / 设置；留安全区。
- 工具页单列；输入与输出上下堆叠。
- 触控目标 ≥ 34px；卡片最小高度 140px。

## 5. 组件

### 工具卡片

- 面板底 + 极轻的斜向高光；1px 边框；hover 上移 2px 并出现底部荧光线。
- 图标 42px 圆角方块，默认灰线，hover 变荧光绿。
- 名称 15px；描述 12.5px、两行以内；底部徽标（分类 / Worker / Beta）。
- 星标按钮独立，不触发卡片打开。

### 面板（Pane）

- 头部 42px：大写小标签 + 等宽元信息 + 右侧操作。
- 内容区：编辑器/输出区，等宽 12.5px，行高 1.68。
- 底栏：统计 chips；错误态整块淡红背景。

### 选项条

- 一行 flex wrap，12px gap；左侧选项组，右侧主操作。
- 主按钮荧光绿底黑字；次按钮透明底描边；危险操作红色描边。
- 分段控件：3px 内边距，选中项抬升；主强调分段可用荧光绿。

### 数据表

- 表头 sticky，10px 大写字母间距；行 hover 提升对比度。
- 偏移列用弱化色；关键值用荧光绿；数字右对齐。
- 最大高度 52vh，内部滚动；移动端允许横向滚动。

### 命令面板

- 居中偏上（12vh），620px 宽；深色遮罩 + blur。
- 输入行 15px；结果项 32px 图标 + 名称/描述；选中项描边。
- 底部快捷键提示。

## 6. 动效

- 统一缓动 `cubic-bezier(.2,.8,.2,1)`；时长 160–180ms。
- 卡片入场 `rise`：opacity + translateY(7px)，按索引 26ms 递增，最多 12 个。
- 页面切换：淡入 + 4px 位移，150ms。
- 不使用弹跳、旋转、长时动画；尊重 `prefers-reduced-motion`。

## 7. 响应式细节

- 断点：1100px 双栏变单栏；900px 桌面外壳变移动外壳。
- 编辑器最小高度：桌面 44vh；1100px 以下 32vh；移动 30vh。
- 结果卡片 `auto-fill minmax(150–180px, 1fr)`。
- 移动端 toast 位于底部导航上方。

## 8. 可访问性

- 正文对比度 ≥ 4.5:1；大字/元信息 ≥ 3:1。
- 所有交互元素有可见 focus ring（2px 荧光绿）。
- 图标按钮必须有 `aria-label` 或 `title`。
- 错误用文字 + 颜色双重表达。
- 键盘顺序：侧栏 → 主区 → 操作按钮；命令面板支持 ↑↓/Enter/Esc。

## 9. 文案

- 中文优先，英文同步；动词开头：`格式化`、`压缩`、`复制`、`清空`。
- 错误文案说明“哪里错 + 怎么改”，例如“缺少冒号”“Base64 内容不合法”。
- 不使用感叹号；不使用“请点击下方按钮”这类冗余指引。
