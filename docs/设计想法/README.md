## 规则

- 新想法放 `docs/设计想法/<主题>/<文档>.md`，开头写清“要解决什么问题 / 当前结论 / 落地状态”。
- 已落地的设计，在对应顶层文档（架构/需求/UI）更新为现行事实；本目录只保留“为什么当初这么想”。
- 不确定的方案标注 **探询中**，不要写成已决策。
